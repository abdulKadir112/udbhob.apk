# Udbhob (উদ্ভব) - React Native Mobile Application 📱

প্রবাসীদের যৌথ সঞ্চয়, ১২ মাসের কিস্তি পেমেন্ট ম্যাট্রিক্স, রিয়েলটাইম চ্যাট এবং হালাল বিনিয়োগ প্রকল্পের সম্পূর্ণ **React Native (Expo)** মোবাইল অ্যাপ্লিকেশন।

এই কোডবেসটি দিয়ে আপনি সরাসরি **Android APK** তৈরি করে গুগল ড্রাইভে রাখতে পারবেন অথবা **AAB** তৈরি করে গুগল প্লে স্টোরে (Google Play Store) আপলোড করতে পারবেন।

---

## 🚀 ফাইল ডাউনলোড ও প্রজেক্ট সেটআপ

১. AI Studio-র উপরের ডানপাশের সেটিংস (⚙️) থেকে **"Export as ZIP"** অথবা **"Export to GitHub"** এ ক্লিক করে কোড ডাউনলোড করুন।
২. আপনার কম্পিউটারে ফোল্ডারটি ওপেন করুন এবং টার্মিনালে `react-native-udbhob` ফোল্ডারে যান:

```bash
cd react-native-udbhob
npm install
```

---

## 📲 তাৎক্ষণিক ফোনে চালিয়ে দেখা (Expo Go)

আপনার ফোনে **Expo Go** অ্যাপ (Play Store বা App Store থেকে) ইনস্টল করুন, তারপর রান করুন:

```bash
npx expo start
```
স্ক্রিনে আসা QR Code-টি ফোনের ক্যামেরা বা Expo Go অ্যাপ দিয়ে স্ক্যান করলেই লাইভ অ্যাপটি ফোনে চালু হয়ে যাবে!

---

## 📦 ৫ মিনিটে Android APK ফাইল তৈরি (গুগল ড্রাইভে শেয়ার করার জন্য)

ইউজারদের সরাসরি ইনস্টল করানোর জন্য স্ট্যান্ডঅ্যালোন `.apk` ফাইল তৈরি করার নিয়ম:

১. টার্মিনালে EAS CLI ইন্সটল ও লগইন করুন (ফ্রি একাউন্ট তৈরি করা যায়):
```bash
npm install -g eas-cli
eas login
```

২. সরাসরি ক্লাউড থেকে APK বিল্ড করার কমান্ড দিন:
```bash
eas build -p android --profile preview
```

বিল্ড শেষ হলে Expo আপনাকে একটি সরাসরি **Download Link (.apk)** দিবে। সেই ফাইলটি ডাউনলোড করে আপনার **Google Drive** বা WhatsApp গ্রুপে শেয়ার করে যে কাউকে সরাসরি ইন্সটল করাতে পারবেন!

---

## 🏬 গুগল প্লে স্টোরে (Google Play Store) আপলোড করার নিয়ম

গুগল প্লে স্টোরে আপলোড করার জন্য `.aab` (Android App Bundle) ফরম্যাট তৈরি করতে হয়:

১. কমান্ড রান করুন:
```bash
eas build -p android --profile production
```

২. বিল্ড শেষ হলে প্রাপ্ত `.aab` ফাইলটি [Google Play Console](https://play.google.com/console)-এ আপলোড করুন।
